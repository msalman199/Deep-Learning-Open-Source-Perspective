## 🎯 Overview

> 💡 **Lab Environment:** Al Nafi Ubuntu machine — everything in this lab is configured locally, with **no cloud access required**.

This lab walks through building a complete local development environment for **AI, Machine Learning, and DevOps** experiments. It starts with an isolated Python virtual environment, layers on the major deep learning frameworks and Jupyter Notebook, and finishes by installing Docker and verifying it with a running container.

| 🧩 Area | 🛠️ Tooling |
|---|---|
| 🐍 Isolated Development | Python virtual environment |
| 🤖 Deep Learning | TensorFlow, Keras, PyTorch |
| 📓 Interactive Experimentation | Jupyter Notebook |
| 🐳 Containerization | Docker |
