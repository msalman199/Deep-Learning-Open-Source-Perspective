## 🎯 Overview

> 💡 **Lab Environment:** Local machine — everything in this lab runs locally, with **no cloud dependency**.

This lab simulates how **CI/CD** is applied to deep learning workflows. You manage model code in a Git repository, install and configure Jenkins for automation, and build a pipeline that automatically trains a model on each commit or trigger.

| 🧩 Area | 🛠️ Tooling |
|---|---|
| 📦 Version Control | Git repository for deep learning code |
| ⚙️ Automation | Jenkins |
| 🔁 Pipeline | CI/CD pipeline triggering model training |

---

## 🏆 Key Accomplishments

In this lab, you:

- ✅ **Created a Git repository** to manage deep learning code
- ✅ **Installed and configured Jenkins** for automation
- ✅ **Set up a CI/CD pipeline** to automatically train a model upon each commit or trigger

## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|---|---|
| 📦 **Git Repository** | Version-controlled home for the deep learning code |
| ⚙️ **Jenkins** | Automation server installed and configured to run the pipeline |
| 🔁 **CI/CD Pipeline** | Automated workflow that trains the model without manual steps |
| 🪝 **Commit / Trigger** | The events that automatically start a model training run |
| ♻️ **Reproducibility** | Consistent, repeatable results from automated training runs |
| 🛡️ **Reliability** | Dependable workflows achieved through automation |
