## 🎯 Overview

> 💡 **Lab Environment:** Local machine with a local Kubernetes cluster (Minikube or MicroK8s) — **no cloud access required**.

This lab simulates a real-world model deployment workflow. You package a deep learning model inside a Docker container, expose it through a Flask API, and deploy the container on a local Kubernetes cluster.

| 🧩 Stage | 🛠️ Tooling |
|---|---|
| 📦 Packaging | Docker container |
| 🌐 Serving | Flask API |
| ☸️ Deployment | Local Kubernetes (Minikube or MicroK8s) |

## 🏆 Key Accomplishments

In this lab, you:

- ✅ **Packaged a deep learning model** inside a Docker container
