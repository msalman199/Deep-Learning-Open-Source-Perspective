## 🎯 Overview

> 💡 **Lab Environment:** Al Nafi-provided Ubuntu machine — the entire simulation runs **offline**.

This lab simulates serverless scaling logic locally. You build a function that mimics AWS Lambda or GCP Cloud Functions, create autoscaling logic driven by model load thresholds, and run event-based triggers that make real-time decisions about scaling model instances up or down.

| 🧩 Stage | 🛠️ Focus |
|---|---|
| ☁️ Serverless Simulation | Local function mimicking AWS Lambda / GCP Cloud Functions |
| 📏 Scaling Logic | Autoscaling based on model load thresholds |
| ⚡ Event Triggers | Real-time scale up / scale down decisions |
