## 🎯 Overview

> 💡 **Lab Environment:** Local machine — the training script runs locally, and the GPU deployment is a **mock plan** for when real GPU instance access becomes available.

This lab bridges a local training setup with real-world cloud deployment. You prepare and run a GPU-compatible PyTorch training script locally, simulate GPU training behavior using device-selection logic, and create a mock plan for deploying and training on real GPU instances.

| 🧩 Stage | 🛠️ Focus |
|---|---|
| 🖥️ Local Training | GPU-compatible PyTorch script run locally |
| 🎛️ Device Logic | `torch.device("cuda" if ...)` selection |
| ☁️ Cloud Planning | Mock plan for training on real GPU instances |
