## 🎯 Overview

> 💡 **Lab Environment:** Local machine — a local folder acts as a private storage bucket, so **no live cloud access is required**.

This lab simulates securing a deep learning model in cloud storage. You use a local folder as a private bucket, restrict access to the model file with Linux permissions, encrypt it with GPG/OpenSSL, and write a mock access policy and audit log system.

| 🧩 Security Layer | 🛠️ Tooling |
|---|---|
| 🪣 Storage Simulation | Local folder as a private bucket |
| 🔑 Access Control | Linux permissions + mock access policy |
| 🔒 Encryption | GPG / OpenSSL |
| 📜 Logging | Mock audit log system |
