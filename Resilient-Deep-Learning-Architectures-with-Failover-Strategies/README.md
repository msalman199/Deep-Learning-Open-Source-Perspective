## 🎯 Overview

> 💡 **Lab Environment:** Ubuntu machine — the entire simulation runs **offline**.

This lab simulates resilient cloud architecture practices locally. You deploy two replicas of a deep learning model, implement `/health` endpoints for real-time availability checks, and create a local failover system that monitors replicas and routes requests to healthy ones.

| 🧩 Stage | 🛠️ Focus |
|---|---|
| 🧬 Replication | Two replicas of a deep learning model |
| 🩺 Health Checks | `/health` endpoints for real-time availability |
| 🔁 Failover | Monitoring and routing requests to healthy replicas |

## 🧠 Key Concepts

| 🔑 Concept | 📖 Description |
|---|---|
| 🧬 **Model Replica** | One of two deployed copies of the deep learning model |
| 🩺 **`/health` Endpoint** | An endpoint used for real-time availability checks |
| 🔁 **Failover System** | Local logic that monitors replicas and routes requests to healthy ones |
| 🏗️ **High Availability** | Keeping the application available when a replica is unhealthy |
| 🩹 **Self-Healing Deployment** | Deployments that continue serving through failures |
