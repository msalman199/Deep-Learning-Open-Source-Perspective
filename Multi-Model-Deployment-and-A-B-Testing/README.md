## 🎯 Overview

> 💡 **Lab Environment:** Al Nafi-provided Ubuntu machine — the entire simulation runs **fully offline**.

This lab simulates multi-model deployment and A/B testing locally. You deploy two separate versions of a model API using Flask, place Nginx in front as a local load balancer to distribute traffic between them, and verify that requests are routed across the model variants.

| 🧩 Stage | 🛠️ Tooling |
|---|---|
| 🌐 Model APIs | Two separate Flask model API versions |
| ⚖️ Load Balancing | Nginx distributing traffic (A/B testing) |
| ✔️ Verification | Confirming traffic routes between model variants |
