## 🎯 Overview

> 💡 **Lab Environment:** Al Nafi-provided Ubuntu machine — everything runs **completely offline**.

This lab covers continuous monitoring and observability for AI systems. You install and configure the ELK stack locally, simulate real-time logging from a deep learning model, and use Kibana to visualize model performance metrics such as accuracy and latency.

| 🧩 Stage | 🛠️ Tooling |
|---|---|
| ⚙️ Setup | ELK stack installed and configured locally |
| 📝 Logging | Simulated real-time logs from a deep learning model |
| 📈 Visualization | Kibana dashboards for accuracy and latency |
