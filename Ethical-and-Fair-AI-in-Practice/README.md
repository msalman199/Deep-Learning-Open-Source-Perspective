## 🎯 Overview

> 💡 **Lab Environment:** Ubuntu machine — everything runs locally, with **no cloud dependency**.

This lab introduces fairness in machine learning. You use open-source tools (`fairlearn`, `scikit-learn`) to identify and measure bias, train a simple classifier, test it against fairness metrics, and quantify disparities in prediction outcomes across sensitive features such as gender.

| 🧩 Stage | 🛠️ Tooling |
|---|---|
| 🤖 Model Training | `scikit-learn` simple classifier |
| ⚖️ Fairness Measurement | `fairlearn` fairness metrics |
| 📊 Disparity Analysis | Prediction outcomes across sensitive features (e.g., gender) |
